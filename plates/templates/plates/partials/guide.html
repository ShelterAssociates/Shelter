DIGIPIN and Plus Code plates: how to use

This guide explains how to make house plates in the Shelter web app, how to change the plate designs (templates), and how the feature is set up and maintained. Parts 1 to 5 are for everyone who makes plates. Part 6 is for people who change templates. Part 7 is for developers and administrators.

1. What the plates feature does

A plate shows one house's address code, its slum name and a QR code that opens the location on a phone. There are two plate types, and each run makes only one type:

  • DIGIPIN plate: the 10-character India Post DIGIPIN (printed as 3-4-3, for example 4J6 M828 6K8), the DIGIPIN symbol and the India Post logo. The QR opens the India Post DIGIPIN page.
  • Plus Code plate: the Google plus code (for example 7J8PMFV5+5RCH) and the Google Maps logo. The QR opens Google Maps at the house's latitude and longitude.

The standard plate is 5 x 1.5 inches (127 x 38.1 mm), drawn at 600 DPI (3000 x 900 pixels), with two drill-hole marks (4.5 mm, centres 5 mm from the left and right edges). Every plate is a PNG image with the print size stored inside it, so print software prints it at the right size.

The data always comes from what you type or upload. Nothing is read from the mastersheet.

2. Who can use it

  • Making plates (single plate, Excel upload, batches): members of the group sticker_plates_generation, and superusers. The Plates link appears under Tools in the top menu only for these users.
  • Changing templates, logos and fonts: superusers, and members of the groups listed in the setting PLATES_TEMPLATE_GROUPS.
  • You see and download only your own batches. Superusers see everyone's.
  • Anyone else who opens a plates page sees "You do not have access to this page." Being staff alone is not enough. A user who is not logged in is sent to the login page.

To give someone access, an administrator adds them to the group in Admin → Database administration → Users.

3. Make one plate

  1. Open Tools → Plates → Single plate.
  2. Choose the plate type (DIGIPIN or Plus Code) and the template. Only templates of the chosen type are listed; the default one is picked for you.
  3. Fill in the fields. Fields marked with a red * are required:
    • Code: the DIGIPIN or plus code. For a DIGIPIN plate you may leave it empty; it is then worked out from the latitude and longitude.
    • Latitude and Longitude: decimal degrees inside India (latitude 2.5 to 38.5, longitude 63.5 to 99.5).
    • Slum Name: printed under the code, followed by the template's suffix (for example ", IMC").
    • House No: up to 5 characters, used in the file name.
    • Ward, City: optional.
  4. Choose the options:
    • Drill holes (ticked by default): untick it for a full plate or sticker without the hole marks.
    • Side panel: adds a 19.1 mm strip on the side with the house number and slum name. It is cut off and kept for matching plates to houses. The image becomes wider by that strip.
  5. Press Preview to see the plate. Press Download PNG to save it at full print size. The file is named code_house-number, for example 4J6M8286K8_1.png.

Nothing is stored on the server. You can make up to 60 single plates a minute.

4. Make many plates from an Excel file

4.1 Fill in the Excel format

On Plates → Excel upload, press DIGIPIN Excel format or Plus Code Excel format. Fill in the Plates sheet, one row per plate, and keep the header row as it is. The Instructions sheet repeats these rules.

ColumnRequiredRule
House NoYesUp to 5 characters, e.g. 1, 12A, 0045. 12.0 is read as 12.
DIGIPIN or Plus CodeYesDIGIPIN: 10 characters from 2-9 C F J K L M P T; spaces and hyphens are removed, so 372-8F3-7K28 is fine. Plus code: 8 characters, "+", then 2 to 4 characters, e.g. 7J8PMFV5+5RCH. Short codes with a place name are not accepted.
LatitudeYes2.5 to 38.5
LongitudeYes63.5 to 99.5
Slum NameYesUp to 80 characters; < and > are not allowed.
Ward, CityNoUp to 40 characters. City is used in the zip name.
  • Header names are matched without caring about capitals or extra spaces. The header row is the first row that is not empty.
  • You may add your own columns after these (survey id, remarks). They are copied unchanged into the result file.
  • Type values, not formulas. A formula in a required column skips that row ("Slum Name contains a formula; type the value instead").
  • Save as Excel Workbook (.xlsx). Up to 15,000 rows and 10 MB. Files with macros, .xls and .csv files are refused.

4.2 Upload

Choose the plate type and template, choose the file, and if the workbook has several sheets, give the sheet name (empty means the first sheet). Choose Drill holes and Side panel as for a single plate. Press Upload and check.

If a required column is missing, the upload stops straight away and names the missing columns, with the full list of expected headers. Nothing is kept.

4.3 Check the rows

The check page reads every row and shows:

  • Rows, plates to make, skipped rows (each with its reason), warnings, duplicate codes and renamed files. The first 50 of each list are shown; Download the full list gives all of them as an Excel file.
  • Skipped rows never stop the batch. The other rows still become plates. If no row can be made, the batch cannot be queued.
  • Warning, DIGIPIN does not match Latitude/Longitude: the DIGIPIN worked out from the coordinates is different from the one in the file. The plate is still made with the code from the file. Check that row.
  • Same DIGIPIN as row ...: one DIGIPIN covers about 4 x 4 m, so close houses can share it. The plates are made; decide whether that is right.
  • Renamed files: two rows with the same code and house number. The second file gets _2 (the third _3), for example 4J6M8286K8_1_2.png.

4.4 Demo plates and confirm

Up to three demo plates are drawn exactly as they will print: the first row, the row with the widest code and the row with the longest slum name. Each shows its file name and the QR link. Look at them carefully. Then check Send emails to (filled in with your account's email; change it if needed; it must be an @shelter-associates.org address), tick I have checked the demo plates and press Generate N plates. The button stays off until the box is ticked.

After you confirm, the batch is queued and you get an email. The server picks it up within about 2 minutes and makes the plates one by one. The batch page shows progress every 100 plates and refreshes by itself. You can have one queued or running batch at a time.

4.5 Download

When the batch is done, the address you gave gets an email "Plates ready" with a Download zip button (you are asked to log in). The developer gets a copy of every batch email. You can also download from Plates → Batches: finished batches have a Download button in their row, and clicking anywhere on a row opens the batch page. The list can be searched, filtered by status and sorted by any column. The zip contains:

  • images/: one PNG per plate, named code_house-number, e.g. 4J6M8286K8_1.png or 7J8PMFV5+5RCH_1.png.
  • plates.xlsx: the Plates sheet has every uploaded column in the original order, then Image file name, Status (made or skipped), Reason, Code on plate and QR link. The Batch sheet records the template and version, size, DPI, drill holes, side panel, and who asked for and confirmed it, and when.

The zip name is <city or slum>_<plate type>_<date>_batch-<number>.zip.

6. Templates: change the design of a plate

A template is a saved plate design: size, DPI, background, logos, fonts, positions of every element, drill holes, side panel, QR link and the text under the QR. Open Plates → Templates (template editors only).

6.1 Versions

  • Every saved change to how a template looks makes a new version. The old version becomes read-only and is switched off, so earlier batches can be made again exactly as before. Changing only the name, Default or Active keeps the same version.
  • Archive (Templates page or the editor) hides a template from every picker; it moves to Archived templates (button next to New template). Restore brings it back. If you archive the default template, mark another one as default.
  • Delete permanently is only offered in the Archived list and asks for confirmation. It removes the template and all its older versions and cannot be undone. A template that was used for any batch cannot be deleted, so that batch can always be made again; it simply stays archived.
  • Default picks the template that is chosen automatically for its plate type and kind. There is one default per plate type and kind.

6.2 Create, copy, edit

  • New DIGIPIN template / New Plus Code template starts from the current default of that type.
  • Copy makes an independent copy to try a different size or look; the original stays unchanged.
  • The editor shows a live preview on the right. Tick Show the longest values to see the widest code (MMM MMMM MMM) and a 60-character slum name.

6.3 The settings

SettingMeaning

Width, Height (mm), DPIPrint size without the side panel. 5 x 1.5 in is 127 x 38.1 mm; 5 x 1.25 in is 127 x 31.75 mm. 600 DPI for printing, 300 DPI for smaller files.
BackgroundDesigned (gradient or solid colours, faint grid, rounded border, tricolour strip), or an uploaded background image.

Side panelOn or off, left or right, width, style (labelled, centred grey, old style), which fields to show, dashed cut line. A 19.1 mm panel fits slum names up to about 30 characters; rows with longer names are skipped.
QR linkThe link inside the QR (see 6.5).
Text under QRFixed text printed under the QR on every plate, e.g. SCAN FOR LOCATION. Empty hides it.

6.4 Elements

The Elements table lists every part of the plate: texts, the QR, logos, white cards, the badge circle and lines. For each element:

  • Left and Top (mm): where the element's box starts, measured from the plate's left edge and top edge. To move something left, make Left smaller; right, make it bigger. To move it up, make Top smaller; down, make it bigger. 1 means 1 mm.
  • Width and Height (mm): the size of the element's box.
  • Layer: drawing order; higher numbers are drawn on top.
  • Font (texts) or logo (images, badge): pick from the installed fonts and logos. auto:india_post_logo means "the default India Post logo".
  • Largest and Smallest (pt): font size in points. The text starts at the largest size and shrinks until it fits its box. If it still does not fit at the smallest size, long names wrap onto a second line (codes never wrap). If it still does not fit, that row is skipped with "Text too long for ...".
  • Colour: #RRGGBB, e.g. #2A2468.
  • Text: for fixed texts such as the title DIGIPIN.

Example: move the badge circle a little to the left. Its Left is 8.93 mm; change it to 8.75. The preview updates straight away. Every element must stay at least 1.5 mm away from a drill hole, so with drill holes on, 8.72 mm is as far left as the badge can go; the editor tells you if you go further ("badge" is closer than 1.5 mm to a drill hole). To move it more, untick Drill holes or reduce Hole centre from edge, or move the badge right instead.

Behind the scenes the template stores every position as a share of the plate, so when you change the plate size the layout keeps its shape and the millimetre values in the table change with it.

Advanced settings (alignment, letter spacing, shadows, ring widths, which data a text shows) are in All element settings (JSON). Text sources are: fixed, qr_caption, digipin, digipin_display, pluscode, slum, house_no, ward, city, lat, long.

6.5 QR link helper

  1. Pick a starting link: India Post DIGIPIN page, Google Maps from coordinates, or Google Maps search by plus code.
  2. Insert variables with the buttons: {house_no} {digipin} {digipin_display} {pluscode} {lat} {long} {slum} {ward} {city}.
  3. The helper shows the finished link for a sample row and a test QR. Scan it with a phone.

A link must start with https:// and point only to dac.indiapost.gov.in or www.google.com, so a template can never send people to another site. Values are encoded safely (a + becomes %2B).

6.6 Checks before a template is saved

  • No two elements overlap, except elements inside their own card or badge.
  • No element is closer than 1.5 mm to a drill hole or the plate edge.
  • Text that changes per row cannot shrink below 6 pt when printed.
  • The QR is at least 15 mm with a blank margin of at least 2 QR modules.
  • The longest values fit: code MMM MMMM MMM (or WWWWWWWW+WWWW), a 60-character slum name and a 5-character house number.

Each problem is explained in plain words, for example "code" overlaps "qr_card". Move or resize one of them.

6.7 Example: a 5 x 1.25 inch sticker with a side panel

  1. On the Templates page press Copy next to the DIGIPIN template.
  2. Set Plate or sticker to Sticker (drill holes switch off), Height to 31.75.
  3. Tick Side panel, choose its fields, and check the preview.
  4. If the editor says a text can shrink below 6 pt, raise that text's Smallest size a little (e.g. slum 0.06 to 0.07), then save.

6.8 Logos, background images and fonts

  • Images: PNG or JPEG only (no SVG), up to 5 MB and 4000 pixels a side. Kinds: DIGIPIN symbol, India Post logo, Google Maps logo, background, other. Tick Default to use an image wherever a template asks for that kind automatically. Use transparent PNGs for logos.
  • Fonts: .ttf or .otf files that open correctly. For a variable font, give the style name, e.g. Bold.
  • Files are stored privately and are never reachable by a web address.

7.2 First-time setup on a server

  1. ENV3/bin/pip install qrcode==7.3.1 (also in requirement.txt).
  2. python manage.py migrate plates: creates only the plates_* tables.
  3. python manage.py seed_plate_presets: the sticker_plates_generation group, fonts, logos and the two approved templates. Safe to run again; it never changes templates edited in the editor.
  4. python manage.py collectstatic.
  5. nginx: the location ^~ /media/plate_ { deny all; return 403; } rule (in deploy/nginx/prod.conf and uat.conf), then nginx -t and reload.
  6. Cron: deploy/JOB_QUEUE_RUNNER.sh every 2 minutes and deploy/CLEANUP_GENERATED_FILES.sh at 05:00 (the cleanup now also removes plate_exports and runs cleanup_plate_uploads).
  7. Settings in local_settings.py if needed: PLATES_GROUPS, PLATES_TEMPLATE_GROUPS.
  8. python manage.py seed_notification_config: adds the Plates batch copy email purpose (developer gets a copy of every batch email). Change its recipients in Admin → Email purposes.
  9. Add the users to the group, restart the app, make one single plate of each type, print at 100% scale, measure 5 x 1.5 in and scan the QR with phones.

7.4 How a batch runs

Confirming creates a notification.JobRequest with job key plate_batch and params {"batch": public_id}. The cron runner claims it, calls plates.services.batch.run, which checks disk space, reads the stored Excel again, draws each plate into a temporary zip (progress every 100), adds plates.xlsx and renames the zip into media/plate_exports/<random>/ only when complete. Done and failed batches are emailed. If a run is killed (deploy, restart), the queue's orphan sweep fails the request after 6 hours and the batch is marked failed the next time a plates page or the nightly cleanup looks at it, and the user is emailed once. The AVNI activity-report email is skipped for this job.

7.5 Security

  • Every page needs login and the plates permission; batches are reached by a random id and only by their owner or a superuser.
  • Files are served only through Django views (attachment, no-store); all /media/plate_* folders are blocked in nginx and in PRIVATE_MEDIA.
  • Excel uploads: .xlsx only, no macros, zip-bomb and DOCTYPE checks, formulas never evaluated. Cells starting with = + - @ tab or CR get an apostrophe in plates.xlsx.
  • Every action is logged in PlateActivity (admin, filterable).

7.6 Tests and this guide
